# Counter App - iOS Architecture Practice

Простое приложение-счётчик для изучения архитектур iOS (MVVM, VIPER, Clean Architecture).

## Цель проекта
Написание простейшего приложения с практическим применением архитектурных паттернов MVVM и VIPER.

## Функциональность
- Увеличение счётчика (+)
- Уменьшение счётчика (-), минимум 0
- Сброс счётчика (Reset)

## Архитектуры
- [ ] MVVM (Model-View-ViewModel)
- [ ] VIPER (View-Interactor-Presenter-Entity-Router)
- [ ] Clean Architecture + MVVM
- [ ] Clean Architecture + VIPER

## Технологии
- Swift 5.9+
- SwiftUI
- Combine (для реактивного биндинга)
- XCTest (для юнит-тестов)

## Структура проекта
```
CounterApp/
├── MVVM/              # MVVM версия
├── VIPER/             # VIPER версия
├── CleanMVVM/         # Clean Architecture + MVVM
└── CleanVIPER/        # Clean Architecture + VIPER
```
